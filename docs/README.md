## 현재 기록의 범위

2026년 10월 20일 감사와 후속 검토에서 일반판 한국어 원본과 영어 번역의 37개 파일·2,971개 키 전체를 대조하고, 10개 파일의 14개 값을 수정했다. 이후 국가 선택 GUI 변경에서도 이 현지화 파일과 키 구성을 보존했다. 실제 실행에서는 일반판의 국가 선택·중점·국가 정신·결정·이벤트에 영어가 적용됨을 표본으로 확인했다.

국가 선택 설명은 표시 영역 확대와 스크롤바를 적용한 후보의 1920×1080 실행과, 동일한 GUI 파일을 배포한 설정상 1280×720 실행에서 한국의 영문 설명 세 문단을 읽을 수 있음을 확인했다. 배포본은 English·창 모드·UI 배율 1.0에서 일반판 HoK와 이 번역 두 모드만 활성화했다. 720 실행에서는 스크롤바를 내려 한국의 마지막 문단 전체를 확인했고, 독일의 짧은 두 문단 설명과 국가 선택 버튼도 정상 작동했다. 이 결과는 확인한 국가 선택 설명 범위의 PASS다.

적용 파일은 설치된 HOI4 1.19.3의 전체 `interface/frontendgamesetupview.gui`에서 해당 설명의 높이와 스크롤바 두 속성만 바꾼 것으로, 여러 국가가 공유하는 위젯에 적용된다. 다른 UI 모드와의 호환성은 미검증이며, 게임 업데이트 시 원본 파일과 재대조해야 한다. 세부 조건과 근거는 [UI 검증 기록](2026-10-20-ui-verification.md)을 따른다.

긴 도입 이벤트의 넘침은 **미해결**이다. 기존 1280×720·1920×1080 실행에서 선택지가 화면 밖으로 내려갔고, C1·C2·C3 시험도 본문 전체와 선택지의 사용성을 함께 확보하지 못했다. 특히 C2·C3는 본문이 잘려 채택하지 않았다. 일반 이벤트용 GUI는 배포하지 않았으며, 국가 선택 설명의 개선을 이벤트 문제의 해결로 간주하지 않는다.

Korean Language를 추가한 비교 실행의 한영 혼용 FAIL도 유지한다. 기본 UI는 한국어, 표본 HoK 문구는 영어로 섞였다. 초기 A/B 실행 근거는 [구현·실행 기록](2026-10-20-implementation.md)에 있다.

RT56에서는 서로 다른 지역을 뜻하는 주 ID 8개의 정적 충돌을 재확인했다. 정적 호환성 FAIL을 유지하며, 별도 빌드는 미구현이고 게임은 미검증이다. 원본 기준 기록과 키 재계산만 완료한 [RT56 지원 설계](rt56-compatibility-design.md)와 실제 지원 완료를 구분한다.

날짜가 같은 초기 감사와 후속 실행을 구별한다. 초기 감사의 NOT TESTED는 당시 기록이며, 현재 상태는 후속 구현·실행 기록에 적는다. 이후 원본, 번역, 게임 버전이나 모드 구성이 바뀌면 이전 결과를 그대로 적용하지 말고 변경된 조건을 기록한다.

## 문서와 검증 자료의 저장 위치

`docs/`에는 사람이 읽을 검증 기록과 절차를 둔다. 테스트 스크립트, 임시 보고서, 원본 JSON, 로그 사본, 스크린샷과 백업은 다음 외부 전용 폴더에 둔다.

```text
C:\hoi\test\hok-english-translation-anime\<task-or-run-id>\
```

해당 로컬 자료는 이 저장소에 포함돼 있다고 가정하지 않는다. 기존 자료를 삭제하거나 이 폴더로 이동하지 않는다.
