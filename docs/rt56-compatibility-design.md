# RT56 영어 번역 지원 설계

상태: **설계 완료 / 별도 번역 빌드 미구현 / 실제 게임 NOT TESTED**.

이 문서는 2026년 10월 20일 확인한 정적 충돌을 바탕으로 향후 지원 구조를 정한다. 현재 일반판 번역의 기준은 계속 `C:\hoi\hearts_of_korea`다. 사용자가 지정한 RT56판 원본은 `C:\hoi\hearts_of_korea_Road_to_56`이며, 일반판 원문을 대체하는 기준으로 사용하지 않는다.

## 재검토 기준

2026년 10월 20일 두 원본의 현재 키 구성을 다시 계산하고, 현재 일반판 영어 번역과 설치된 RT56의 주 이름을 대조했다. 기존 설계 수치와 주 ID 8개의 정적 충돌은 그대로였다.

| 항목 | RT56판 재검토 기준 |
| --- | --- |
| 한국어 원본 경로 | `C:\hoi\hearts_of_korea_Road_to_56` |
| 브랜치 | `feat/korean-focus-update-20260922` |
| HEAD | `bf2b997f9d7ddc1710533e9700b641f2fb9e8ce0` |
| 작업 트리 | 재검토 당시 미커밋 변경 없음 |
| descriptor의 모드 버전 | `0.1.0-dev` |
| descriptor의 지원 게임 버전 | `1.19.*` |
| 재검토일 | 2026년 10월 20일 |

이 버전 표기는 원본의 `descriptor.mod`에서 읽은 값이며, 해당 게임 버전에서 RT56 영어 번역을 실행해 검증했다는 뜻이 아니다. 비교한 일반판 원본은 `feat/korean-focus-expansion-ai`의 `d4031aaa0c1f85bb89b0e6ca21d041beade8bd26`이며 작업 트리에 미커밋 변경이 없었다.

## 별도 번역 구성을 선택하는 이유

일반판의 한국어 키 2,971개와 RT56판의 2,743개는 완전히 같지 않다. 공통 키는 2,716개, 일반판 전용은 255개, RT56판 전용은 27개이며, 공통 키의 한국어 값도 25개 다르다.

현재 번역이 정의한 `STATE_1028` 등 주 ID 8개는 RT56에서 다른 지역을 뜻한다. 일반판 번역을 켜 둔 채 RT56용 키만 덧붙이면 일반판 전용 값이 계속 다른 지역을 덮을 수 있다. 따라서 **일반판과 RT56에 각각 필요한 키만 포함하는 별도 번역 빌드**를 설계안으로 선택한다.

일반판 빌드는 37개 파일·2,971개 키를 유지한다. 향후 RT56 빌드는 검증 시점의 RT56 호환판 한국어 키 목록을 기준으로 별도로 만든다. 두 영어 번역 빌드를 동시에 활성화하지 않는 구성이 목표다. 일반판의 `localisation/` 아래에 RT56용 파일을 함께 넣어 조건 없이 로드되게 하지 않는다.

## RT56 빌드의 문자열 구성

| 분류 | 현재 규모 | 처리 방법 |
| --- | ---: | --- |
| 공통 키 중 한국어 값이 같은 항목 | 2,691개 | 일반판 영어를 재사용 후보로 삼되, 참조·파일 경로·용어를 확인 |
| 공통 키 중 한국어 값이 다른 항목 | 25개 | RT56판 한국어와 연결 스크립트를 대조해 별도 번역 |
| RT56 전용 키 | 27개 | RT56판 한국어의 의미·수치·조건에 맞춰 새로 번역 |
| 일반판 전용 키 | 255개 | RT56 빌드에 넣지 않음; 일반판 빌드에서는 유지 |

공통 값이 같은 것만으로 게임상 의미까지 같다고 확정하지 않는다. 특히 지명, 동적 참조와 지역 조건을 확인해야 한다. 값이 다른 25개 중 24개는 만주 관련 설명이고 1개는 RagnaROK 관련 문구다. 일반판 설명에 지역 키를 일괄 치환하는 방식으로 확정하지 않는다.

RT56 전용 27개 키는 다음 4개 파일에 분포한다. RT56 전체 36개 영어 파일은 현재 일반판 번역과 상대 경로가 겹친다.

| 상대 파일 경로 | 전용 키 수 | 내용 |
| --- | ---: | --- |
| `HoK_achievements_l_english.yml` | 1 | RT56판 업적 항목 |
| `HoK_start_game_setup_l_english.yml` | 3 | `hokRagnarok.7.t`, `.d`, `.a` |
| `replace/HoK_countries_l_english.yml` | 3 | `PHI_free_democratic`, `_DEF`, `_ADJ` |
| `replace/HoK_state_name_l_english.yml` | 20 | RT56판 주·승점 이름 |

현재 확인한 주 ID 충돌은 `STATE_1028`, `STATE_1029`, `STATE_1030`, `STATE_1031`, `STATE_1082`, `STATE_1083`, `STATE_1084`, `STATE_1088`이다. RT56 빌드에서는 대응 한국어 원본에 없는 일반판 정의를 제외하고, RT56와 호환판이 소유하는 지명을 보존하는지 실제 화면으로 확인한다. 키 8개만 처리하면 전체 호환성이 해결된다고 간주하지 않는다.

## 파일과 배포 식별자

향후 생성·검증 과정은 공통 번역 자료와 대상별 차이를 입력으로 삼되, 결과물은 일반판과 RT56판을 각각 구성한다. 각 빌드의 키 집합이 해당 한국어 원본과 정확히 대응하는지 검사한다.

시험용 RT56 결과물과 생성 도구는 `C:\hoi\test\hok-english-translation-anime\<task-or-run-id>\` 아래에서 검증한다. 검증 전 결과물을 현재 일반판 배포 파일에 복사하지 않는다.

현재 일반판의 Workshop ID `3823285419`를 별도 RT56 항목의 ID로 복사하지 않는다. 별도 항목을 배포할 경우에는 이름, 업로드 대상, 경로와 필요한 의존성을 구분한다. 일반판의 기존 의존성 두 개는 실제 로드 문제의 근거 없이 삭제하지 않는다. 이 설계 작성에서 descriptor, 등록된 `.mod`, Workshop 항목은 변경하지 않았다.
