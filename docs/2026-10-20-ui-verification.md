# 2026-10-20 UI 검증과 배포 범위

국가 선택 화면의 역사 설명을 읽을 수 있도록 `interface/frontendgamesetupview.gui`의 **역사 텍스트 높이와 스크롤바 두 속성만 수정해 배포 파일에 반영**했다. 1920×1080 외부 후보 시험과 실제 배포 경로를 사용하는 1280×720 후속 확인에서 역사 설명의 스크롤과 국가 선택을 확인했다.

일반 이벤트 창의 긴 본문 문제는 해결하지 못했다. 시험한 C1·C2·C3는 각각 창의 화면 넘침이나 본문 잘림이 남아 채택하지 않았고, 배포 폴더에 `eventwindow.gui`를 추가하지 않았다. 이 두 UI 문제의 결과를 구분한다.

**남은 문제:** 긴 도입 이벤트의 넘침은 미해결이다. 시험용 설정과 모드 등록은 복원했지만, 자동 승인 검토가 임시 폴더 삭제를 차단해 외부 테스트 폴더의 임시 파일 79개는 정리하지 못했다. 이 파일들은 현재 활성 모드 경로에 연결돼 있지 않다.

## 배포한 국가 선택 역사 설명 수정

대상은 설치 게임의 `interface/frontendgamesetupview.gui` 안에 있는 `gamesetup_interesting_countries_window/history`다. 변경은 다음 두 속성뿐이다.

```diff
- maxHeight = 30
+ maxHeight = 190
+ scrollbartype = "standardtext_slider"
```

`fixedsize`는 추가하지 않았다. 폰트·위치·너비·텍스트·다른 위젯은 유지했다. 선언된 부모 높이는 717이고, 역사 설명의 y 좌표 502에 높이 190을 더하면 692로 부모 아래까지 25의 여유가 있다. 이 수치는 정적 배치 근거이며 실제 스크롤 작동을 대신하는 검증은 아니다.

읽기 전용 독립 검사에서 배포 파일 전체가 **설치 원본에 이 두 속성만 반영한 결과와 바이트 단위로 일치**했다. 외부 후보와 배포 파일의 해시도 같다.

## 짧은 일반 이벤트의 회귀 확인

실행 03에서 일반판 원본과 이 영어 번역만 활성화한 1936년 한국 새 게임으로 왕정 입구 중점 `KOR_urihwangsilsaranghoe`를 선택했다. 중점의 7일 소요 안내, 영어 설명 전체와 효과가 화면 안에 표시됐고, 완료 후 일반 국가 이벤트 `kor_events.42`가 발생했다.

1936년 1월 7일 01시 일시정지 상태에서 이벤트 제목, 영어 본문 648자 한 문단, 선택지 하나가 모두 화면 안에 들어오는 것을 확인했다. `May Heaven protect the Emperor!`를 눌러 이벤트가 닫히는 것도 확인했다. 조건은 앞의 실제 배포본 확인과 같은 창모드 1280×720 설정, UI 배율 1.0이었다.

이 **짧은 일반 이벤트 한 건은 표본 PASS**다. `eventwindow.gui`를 배포하지 않은 상태에서 정상적인 짧은 이벤트와 응답 동작을 확인한 것으로, 긴 도입 이벤트 `kor_events.0.d`의 화면 넘침이나 모든 일반 이벤트의 표시를 해결했다는 뜻은 아니다.

증거는 실행 03의 `production_720/screenshots/`에 있다.

| --- | --- |
| 왕정 입구 중점의 영어 설명·효과 | `04_royal_focus_description_effect_0.jpg` |

## 채택하지 않은 일반 이벤트 창 후보

긴 도입 이벤트 `kor_events.0.d`의 영어 본문은 **7문단 전체를 현지화에 보존**했다. 문단 삭제·요약·문장 축약으로 창 높이를 맞추지 않았다.

| 후보 | 변경 방향 | 실제 결과 | 판정 |
| --- | --- | --- | --- |
| C1 | 일반 이벤트 `Description`에 텍스트 스크롤바 추가 | 본문을 스크롤할 수 있었지만 외곽 창과 선택지가 1080p 화면 아래로 내려가는 문제 잔존 | FAIL |
| C2 | 스크롤바에 `fixedsize = yes` 추가 | 창과 응답은 화면에 들어오지만 본문은 앞 2문단과 생략 표시로 제한되고 스크롤되지 않음 | FAIL |
| C3 | C2에 `truncate = no` 추가 | 여전히 앞 2문단만 보이고 본문 스크롤이 작동하지 않음 | FAIL |

외곽 창 안에 응답 버튼이 있다는 사실만으로 전체 본문을 읽을 수 있다고 처리하지 않았다. 일부만 보이거나 툴팁에 의존하는 결과는 해결로 채택하지 않았다. 본문 내부 스크롤과 이벤트 외곽 자동 높이가 서로 다른 문제라는 관찰은 있으나, 안전하게 높이를 제한하는 일반 이벤트 수정은 입증하지 못했다.

배포 폴더에는 `interface/eventwindow.gui`가 없다. 설치 게임의 해당 파일도 시험 전 기준과 SHA256이 일치해 다음 네 템플릿을 변경하지 않았음을 확인했다.

- `EventWindow`
- `EventWindow_Operative`
- `EventWindow_leader`
- `EventWindow_News`

따라서 기존 A1·A2에서 관찰한 도입 이벤트의 **초기 화면 넘침 FAIL을 유지**한다. 국가 선택 역사 설명 수정으로 이벤트 창까지 해결됐다고 보고하지 않는다. A1은 첫 중점 완료 뒤의 관찰이며 정확한 게임 날짜를 이 기록에서 확정하지 않는다. A2에서는 1936년 1월 7일의 일시정지 상태가 확인됐다.

## 번역과 원본의 연속성

실행 02의 정적 재검사에서 원본 HEAD·브랜치가 이전과 같고, `.git`을 제외한 원본 **5,520개 파일의 집합과 각 SHA256이 실행 01 기준과 모두 일치**했다. 원본 추가·삭제·변경은 없었다.

영어 현지화도 실행 01 사후 검수 상태와 같았다. 37개 파일·2,971개 키가 대응하며 누락·추가·중복·기본 문자열 형식·버전·보호 토큰·동적 표현 차이의 새 오류는 없었다. 앞서 적용한 14개 문구·10개 파일의 실제 값과 해시가 유지됐고, 독립 사후 검수도 PASS였다.

전체 번역 대조와 14개 수정의 전후는 [번역 검수와 게임 확인 기록](2026-10-20-implementation.md)에 있다. 원본 내부나 원문과 스크립트 사이의 미해결 사항은 [원문과 구현의 확인 사항](source-review-notes.md)을 따른다. 이 정적 결과를 이번 UI 실행에서 2,971개 문구를 모두 보았다는 뜻으로 사용하지 않는다.

## Korean Language와 RT56

실행 01의 Korean Language 비교 B에서는 저장된 모드 순서가 **Korean Language → 일반판 원본 → 영어 번역**이었고 활성 모드 3개를 확인했다. 기본 메뉴는 한국어, 한국 국호·정당·중점과 일부 한국 승점은 영어로 표시됐다. 영어 전용 구성을 기준으로 **한영 혼용 FAIL**이다.

중복 키 79개를 전부 화면에서 개별 확인한 결과는 아니다. 다른 유효 순서를 비교한 B2는 NOT TESTED이며, 이번 국가 선택 UI 수정이 Korean Language의 메뉴·글꼴·UI 동작을 모두 해결한다는 판정도 내리지 않는다.

RT56는 **설계만 작성했으며 별도 번역 빌드와 게임 검증은 미완료**다. 서로 다른 지역을 뜻하는 주 ID 8개의 정적 호환성 FAIL은 유지한다. 대상별 원본을 혼용하지 않는 별도 구성과 후속 조건은 [RT56 지원 설계](rt56-compatibility-design.md)에 있다.

## 전체 파일 오버라이드의 유지보수 조건

의미 있는 차이는 두 속성이지만 HOI4에는 동일 경로의 GUI 파일 전체가 제공된다. 게임이 업데이트되면 기존 파일을 계속 두는 것만으로 새 버전과 호환된다고 볼 수 없다. 설치 파일의 버전·해시와 바뀐 정의를 확인하고, 해당 버전에 두 속성의 최소 차이만 다시 적용한 뒤 화면을 검증해야 한다.

다른 UI 모드가 `interface/frontendgamesetupview.gui`를 제공하는 경우에도 유효한 로드 순서와 실제 표시를 확인해야 한다. 이번 결과는 명시한 버전과 실행 조건에 한정한다.

## 최종 실행 로그

실행 03의 `system.log`에서 1280×720 창모드, 실행 버전 `b244`, 활성 DLC 36개와 일반판 원본·영어 번역 두 모드를 확인했다. 영어 설정은 로그에 없는 값을 추정하지 않고 보관된 `userdata_after_runtime/settings.txt`의 `language="l_english"`와 실제 화면으로 확인했다.

최종 `error.log`는 130줄·41종이었다. 벽시계와 게임 날짜 필드를 제외한 메시지별 발생 횟수까지 실행 02 이전 로그, 실행 01의 A2 로그, 초기 배포 감사의 기존 로그와 일치했다. **기존 오류가 없는 것은 아니며, 새 GUI·현지화 진단이 추가되지 않았다는 결과**다. 직전 실행 03 백업의 128줄·40종과 비교할 때 추가된 로그 이름 변경 오류 두 줄도 그 이전 세 기준에 이미 있던 메시지였다. 원인은 추정하지 않았다.

비교 기준과 메시지별 차이는 실행 03의 `runtime_log_comparison.json`, 최종 정적 범위 검사는 `final_static_review.json`에 있다. 게임 로그에 새 오류가 없다는 이유만으로 미검증 분기나 긴 도입 이벤트를 PASS로 바꾸지 않는다.

## 설정 복원과 임시 자료 정리

검증용 새 게임을 저장하지 않고 종료한 뒤 게임 프로세스가 없음을 확인했다. 등록된 영어 `.mod`, `dlc_load.json`, `pdx_settings.txt`, `gameplaysettings.txt`는 실행 03 직전 백업과 바이트 단위로 같았다. 실제 등록 경로는 원래 번역 폴더이며 외부 후보 폴더를 가리키지 않는다. 런처 데이터베이스와 원본 descriptor의 의존성은 수정하지 않았다.

이전 시험에서 켠 `pause_on_popups`는 실행 02 전의 `no`로 복원했다. 이전 중단 기록은 이 실제 키 대신 `popup_pause`를 검사해 해당 설정이 남아 있었고, 이번 최종 정리에서 바로잡았다. `settings.txt` 전체를 과거 바이트로 덮어쓰지는 않았다. 실행 03 전후에는 이 일시정지 설정 외에 게임이 갱신한 `refreshRate`의 60→90 차이가 있어 이를 보존했다. 창모드 1280×720과 UI 배율 1.0은 원래 설정이다.

실행 02의 생성 기록에 있는 임시 후보 두 폴더는 삭제 전에 절대경로·파일 집합·79개 해시·링크 부재를 확인했다. 미등록 파일은 없었고 검증 근거와 백업은 삭제 대상에서 제외했다. 그러나 자동 승인 검토가 파일별 정리 명령과 범위를 좁힌 두 절대경로의 삭제 명령을 모두 `blocked by policy`로 거부했다. 다른 도구로 삭제를 우회하지 않았다.

따라서 **임시 파일 정리는 BLOCKED**다. 남아 있는 대상은 다음 두 폴더뿐이며, 실제 배포 폴더 밖의 비활성 진단 복사본이다.

```text
C:\hoi\test\hok-english-translation-anime\20261020-implementation-02\event_window_candidate\
C:\hoi\test\hok-english-translation-anime\20261020-implementation-02\country_history_candidate\
```

생성 목록은 실행 02의 `temporary_files_manifest.json`, 삭제 전 검증은 `cleanup_preflight.json`, 차단 결과는 실행 03의 `cleanup_status.json`을 따른다. 결과 JSON·로그 사본·스크린샷·백업과 기존 실행 폴더는 검증 근거로 보존했다. 임시 모드가 현재 활성화돼 있거나 정리가 완료됐다고 보고하지 않는다.
