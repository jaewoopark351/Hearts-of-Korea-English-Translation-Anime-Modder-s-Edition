# 게임 내 검증 절차

이 문서는 반복 실행할 확인 절차와 현재 진행 상태를 구분해 기록한다. 2026년 10월 20일 초기 감사의 실제 게임 검증은 **NOT TESTED**였으며, 이후 A/B 실행 결과는 [구현·실행 기록](2026-10-20-implementation.md), 국가 소개 UI 수정과 후속 확인은 [UI 검증 기록](2026-10-20-ui-verification.md)에 있다. 당시 정적 결과는 [배포 전 검증 기록](2026-10-20-release-audit.md)에 보존한다.

목표는 게임 엔진이 영어 번역을 최종 선택하는지 확인하는 것이다. 파일의 키 개수나 런처에 저장된 순서만으로 완료 처리하지 않는다.

## 실행 조건 기록

검증을 진행할 때 실제 조건을 먼저 기록한다. 원본은 `C:\hoi\hearts_of_korea`의 현재 내용을 기준으로 삼고, 감사 이후 변경 여부를 확인한다.

- 실행 일시와 실제 HOI4 버전.
- 한국어 원본과 영어 번역의 커밋 및 미커밋 변경 여부.
- 사용한 DLC, 플레이셋 이름, 활성 모드의 정확한 이름·버전·경로·순서.
- 게임 언어와 실행 방법, 검증한 시작 시점·국가·분기.
- 기존 저장 게임 사용 여부. 새 게임과 기존 저장 게임의 결과를 구분한다.

테스트 스크립트, 로그 사본, 스크린샷과 결과 자료는 다음 전용 경로의 새 실행 폴더에 보관한다. 기존 로그와 사용자 저장 게임은 삭제하지 않는다.

```text
C:\hoi\test\hok-english-translation-anime\<task-or-run-id>\
```

검증을 위해 사용자 설정을 변경했다면 변경 전후를 기록하고 원래 구성을 복원한다. 원본 게임 코드나 의존성을 임의로 고쳐 결과를 맞추지 않는다. `-userdir`는 이전 격리 실패 기록이 있으므로, 적용 여부를 확인하지 않은 채 별도 환경이라고 간주하지 않는다.

## 테스트 조합

| 조합 | 활성 콘텐츠 | 비활성 콘텐츠·조건 | 현재 상태 |
| --- | --- | --- | --- |
| A: 일반판 영어 기준 | 일반판 Hearts of Korea, 이 영어 번역 | English 사용; Korean Language, 기존 Musan 영어 번역, RT56 및 HoK RT56판 비활성 | 영어 표본·수정한 국가 소개·짧은 왕정 이벤트 PASS / 긴 도입 이벤트의 초기 넘침 FAIL |
| B: Korean Language 비교 | A 구성에 Korean Language만 추가 | 나머지 조건은 A와 동일하게 유지하고 실제 순서 기록 | 실행 완료 — KL → 원본 → 영어 구성에서 한영 혼용 FAIL; 다른 순서 미검증 |
| C: RT56 | The Road to 56, HoK RT56 호환판, 검토된 영어 번역 구성 | 일반판 HoK와 구번역을 섞지 않음; English 사용 | 정적 호환성 FAIL / 게임 NOT TESTED |

A에서 원본 → 영어 번역의 저장된 순서와 실제 활성 경로를 확인한다. 파일 변경이나 모드 조합 변경 후에는 게임을 완전히 재시작해 결과를 확인한다.

B는 A와의 차이를 비교하는 시험이다. Korean Language가 언제나 영어를 덮어쓴다고 가정하지 않는다. 실제 순서, 표시 언어와 글꼴·UI 차이를 함께 기록한다. 순서를 달리 검사했다면 각각 다른 실행으로 구분한다.

C에는 기존 감사에서 확인한 주 ID 8개 충돌과 RT56 전용 키 27개 문제가 있다. 현재 일반판 번역을 그대로 지원 완료로 판정하지 않는다. 별도 호환 구성이 준비되면 해결한 키·파일과 대상 버전을 명시하고 검증한다. Korean Language 및 RT56 한국어 번역의 활성 여부도 따로 기록한다.

## A에서 확인할 화면

다음 항목은 전체 범위의 확인 목록이다. 국가 선택, 도입 중점·이벤트, 시작 국가 정신, 만주 결정과 일부 지명은 표본으로 확인했지만, 전체 항목을 완료한 것은 아니다. 체크는 해당 범위 전체를 확인할 때만 표시한다.

후속 실행에서는 한국 국가 소개의 세 문단을 1080p 후보와 동일 파일을 사용하는 720p 배포본에서 스크롤로 읽을 수 있음을 확인했다. 720p의 왕정 도입 중점과 `kor_events.42`도 제목·전체 본문·선택지 및 응답 후 닫힘을 확인했다. 일반 도입 이벤트 `kor_events.0.d`의 넘침은 미해결이며 이 표본 PASS와 구별한다. 공통 GUI 파일 수정이므로 게임 업데이트와 다른 UI 모드 조합에서는 다시 확인한다.

- [ ] 국가 선택과 게임 시작: 설명, 시작 옵션, 국호가 영어로 표시되는지 확인한다.
- [ ] 한국 국가 중점: 제목·설명·효과 툴팁을 확인하고 검증한 정치 분기를 기록한다.
- [ ] 이벤트: 본문과 선택지, 선택에 따른 후속 문구를 확인한다.
- [ ] 정치 결정: 비용, 조건, 기간, 재사용 대기기간, 취소·환급 안내를 확인한다.
- [ ] 국가 정신과 시민 영향력 UI: 이름, 설명, 수치와 상태 문구를 확인한다.
- [ ] 인물·정당·국가·주·승점 이름: 영어 번역과 실제 대상 지역이 대응하는지 확인한다.
- [ ] 장비 이름과 관련 설명: 미치환 키, 한국어 혼용 여부를 확인한다.
- [ ] RagnaROK 게임 규칙: `RAGNAROK_ENABLED_TEXT`와 관련 안내가 정상 표시되는지 확인한다.
- [ ] 동적 문구: 국가명, 변수, 날짜·기간, `$KEY$` 참조가 실제 값으로 치환되는지 확인한다.
- [ ] 색상·아이콘·줄바꿈·글꼴·잘림: 실제 화면을 확인하고 문제가 있는 키를 기록한다.

1946년 선거 이벤트 `kor_events.71.d`는 시제 수정 문구의 확인 대상이다. `[GetSaemaulUndongName]`과 `HOK_KOR_Get*` 계열은 실제 치환을 확인할 동적 문구의 예다. 이 예만 확인하고 모든 이벤트·분기를 검증했다고 보고하지 않는다.

## 최종 문자열 선택의 근거

원본의 영어 폴더에는 한국어 값이 많이 남아 있으므로, 같은 키의 원본 값과 번역 값을 먼저 대조해 화면에서 구별 가능한 항목을 선택한다. 국가 중점, 이벤트, 결정, 이름 등 여러 화면에서 실제 영어 출력과 해당 키를 연결해 기록한다.

키가 그대로 보이거나 한국어가 섞이면 해당 화면, 키, 관련 파일과 유효한 모드 순서를 함께 조사한다. 문자열 하나가 영어로 보인다는 사실만으로 모든 파일의 우선순위가 검증됐다고 결론 내리지 않는다.

현재 사용자 데이터의 로그 위치는 다음과 같다.

```text
C:\Users\jaewo\OneDrive\문서\Paradox Interactive\Hearts of Iron IV\logs\
```

실제 실행이 사용한 경로와 로그 시각을 확인하고 `system.log`, `error.log`, `text.log` 등 존재하는 관련 로그를 전용 폴더로 복사한다. 파일이 생성되지 않았으면 그 사실을 기록한다. 과거 로그를 이번 실행 결과로 취급하거나, 오류 로그가 조용하다는 이유만으로 표시가 정상이라고 판단하지 않는다.

## 판정과 결과 기록

| 판정 | 적용 기준 |
| --- | --- |
| PASS | 명시한 버전·구성·화면에서 실제 기대 결과를 확인하고 근거를 남김 |
| FAIL | 확인한 조건에서 잘못된 언어·키·치환·지명·표시 등을 재현함 |
| NOT TESTED | 실행하지 않았거나, 접근 실패·증거 부족으로 확인하지 못함 |

결과에는 다음을 포함한다.

1. 실행 조건과 A/B/C 구분.
2. 화면 또는 이벤트, 현지화 키, 기대 결과와 실제 결과.
3. 스크린샷·로그 사본 등 근거의 저장 위치.
4. 확인하지 못한 분기, DLC, 저장 게임 및 표시 조건.
5. 발견한 문제와 수정 여부, 수정했다면 재검증 결과.

저장된 런처 순서, 엔진의 실제 최종 선택, Korean Language 충돌, RT56 호환성을 각각 판정한다. 문서 작성 자체를 검증 근거로 사용하지 않고, 실제 실행에서 확인한 범위만 상태에 반영한다.
