RT56는 한국어 48파일·4,218고유키, 내장 영어 47파일·2,914고유키다. 한국어 전용 호스트 장비·공용 UI와 기존 장비 중복 정의를 이번 신규 번역 누락으로 집계하지 않는다. 일반판 서브모드와 RT56의 주 ID 충돌도 유지되므로, RT56에서는 내장 영어를 사용하고 이 일반판 번역은 비활성화한다. [RT56 구성 기록](rt56-compatibility-design.md)을 따른다.
