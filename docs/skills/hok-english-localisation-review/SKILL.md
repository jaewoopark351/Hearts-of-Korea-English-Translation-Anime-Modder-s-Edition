# 영국 독자를 위한 영어 의미 번역

원본 업데이트·새 콘텐츠·승인된 코드 반영 또는 수정으로 영어 표시를 추가·변경할 때, 또는 낯선 음역·고유명칭·문화 용어의 번역을 검토할 때 적용한다. 적용 대상은 해당 기능의 문구와 연결된 표시다.

원본 선택·작업 권한·파일 보존·검증 산출물 위치는 [AGENTS.md](../../../AGENTS.md)를 따른다. 일반판 작업은 일반판 한국어를 기준으로 한다. RT56 작업이 명시된 경우 해당 판의 한국어를 원문으로 사용하며, 다른 판의 영어는 대조 자료로 구분한다. 두 버전의 키·주 ID·설정을 혼용하지 않는다. 문서·검토만 요청된 작업에서 번역이나 게임 코드를 수정하지 않는다.

## 대상을 먼저 구분한다

- **일반 개념:** 사회 세력·기업집단·제도·직위 등이 무엇을 뜻하고 어떤 역할을 하는지 확인해 자연스러운 영어로 옮긴다. 한국어 음역이 영어 사전에 실렸거나 다른 국가의 바닐라에 쓰였다는 사실만으로 현재 시대·설정·문맥에 적합하다고 판단하지 않는다.
- **실제 고유명칭:** 인명·지명·기업·기관·설정상 이름은 실제 대상과 확립된 영어 표기를 확인한다. 이해하기 쉽다는 이유로 이름을 일반 개념으로 바꾸거나 한국적 배경을 다른 나라의 인물·사건·기관으로 치환하지 않는다. 제목의 대문자 표기만으로 고유명사 여부를 판단하지 않는다.
- **문화적으로 명명된 개념:** 기존 용례와 기능상 의미에 따라 원명을 유지하거나 의미로 옮긴다. 원명을 유지하면 기존 문장에 짧은 역할 설명을 자연스럽게 결합해 독자가 음역만 보고 뜻을 추측하지 않게 한다. 원문에 없는 역사 강의·각주·정치 평가를 덧붙이지 않는다.
- 같은 한국어 단어도 인물·세력, 회사·기관, 소유 재산을 가리킬 수 있다. 협력·체포의 대상인지, 생산과 납품을 맡는 기업인지, 국유화되는 자산인지 문장 전체와 연결 스크립트로 확인한다.

## 이해하기 쉬운 영어와 원문의 논조를 함께 지킨다

- 한국의 역사·문화·정치를 미리 알지 못하는 현대 영국 독자를 기준으로 쓴다. 음역이나 한국어 어순에 기대지 않고 문장 안에서 행위자·대상·역할·조건이 드러나게 한다. 가독성을 위해 정보를 생략하거나 단순화하지 않는다.
- 표준 영국 영어와 실제 영어 게임 용어를 사용하되 고유명사의 공식 표기는 보존한다. 원문에 없는 고어·영국식 농담·유행어를 추가하지 않는다.
- 중립·비판·찬양과 화자의 정치적 관점·감정·풍자·강압을 보존한다. 비판적인 경제 권력집단을 중립적인 기업가로 순화하거나, 비판을 강화하려고 독점·담합·범죄를 새 사실로 추가하지 않는다. `monopoly`, `cartel` 등의 구체적 표현은 실제 원문과 해당 기능의 근거가 있을 때 사용한다.

## 재벌의 현재 용례

재벌 관련 문구를 추가·수정할 때는 먼저 [일반판 용어 선택과 43개 문구 반영 기록](../../2026-11-09-chaebol-terminology.md)을 읽는다. 다음은 해당 문맥에서 확정한 용례이며 다른 경제 집단에 일괄 적용하는 치환표가 아니다.

| 실제로 가리키는 대상 | 현재 표현 |
| --- | --- |
| 경제 권력을 행사하는 인물·세력 | `corporate oligarchs` |
| 기업집단 자체·공공 소유나 국유화 대상인 회사 | `conglomerates` |
| 소유주 재산 | `the oligarchs' assets` |
| 같은 게임 수치를 가리키는 재벌 영향력 | `Oligarchic Influence` |

좁은 시민사회 창의 세력 제목은 `Oligarchs`를 사용하고 연결 설명에서 역할을 전달한다. `Nationalised Conglomerates`처럼 소유권 변경 대상과 사람을 구분한다. 새로운 문맥에서는 한국어 원문과 실제 대상을 다시 확인한다. 내부 식별자의 `chaebol` / `jaebeol`은 표시 단어와 구분해 유지한다.

## 추가·수정할 때의 대조

1. 해당 버전의 최신 한국어 본문 전체와 연결된 이벤트·중점·결정·국민정신·스크립트를 읽고 대상·시점·조건·논조를 확인한다. 기존 영어도 같은 원문과 대조한 뒤 사용한다.
2. 위 대상 구분에 따라 표현을 정하고 관련 이름·설명·조건과 효과 안내·선택지·해금 안내를 확인한다. 공용·동적 표시와 `$KEY$` 치환을 쓰면 호출부와 치환되는 이름까지 추적해 같은 대상의 표현을 맞춘다. 조사 범위는 해당 변경의 영향에 맞춘다.
3. 한국어와 영어를 문장별로 다시 대조해 누락·추가·오역, 수치·부정·가능성·의무와 화자의 어조를 검토한다. 이어 영어만 읽고 한국어 지식 없이 대상과 역할을 이해할 수 있는지 확인한다.
4. 표시 문자열과 기술 구문을 구분해 키·ID·변수·함수·치환·색상·아이콘·이스케이프와 조건·수치를 보존한다. UTF-8 BOM·헤더·경로·기존 줄바꿈 형식도 확인한다. 일반명사 표현을 고쳤다는 이유로 내부 식별자를 개명하지 않는다.
5. 중요한 용어 선택과 근거, 적용 파일·키 및 관련 사용처를 작업 기록이나 결과에 남긴다. 자료로도 풀리지 않는 모호함은 해당 키와 후보 해석을 기록하고 확정을 보류하며, 독립적으로 처리할 수 있는 작업을 계속한다.

소스 대조·정적 검사와 실제 게임 표시 확인은 구분한다. 수정 범위에 필요한 화면 확인 항목을 정하고, 실행하지 못한 표시·동적 치환·잘림은 미검증으로 보고한다. 문서만 수정한 작업에 게임 테스트를 요구하지 않는다.
