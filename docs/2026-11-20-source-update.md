## 의미와 용어 검토

- 민주인사 지원은 기존 제목과 맞춰 `Support Chinese Democrats`, `Support Japanese Democrats`, 국민정신은 `Korean-Sponsored Democrats`를 사용한다. 중국·공산중국과 지정된 14개 군벌의 현존국을 한 번에 지원하며, 기존 지원이 남은 경우 재지원할 수 없다는 조건을 보존했다.
- 지원의 180일, 각 수혜국의 일일 민주주의 지원 `+0.10`, 새로 등장한 국가의 다음 지원부터 포함, 정권·외교관계 변경 후 남은 기간 유지, 취소·환불 불가를 모두 옮겼다. 결정의 25 정치력 비용은 코드의 자동 표시에 맡기며 원문 본문에 없는 수치를 추가하지 않았다.
- 산둥의 국호는 기존 국가명 `Free Republic of Shandong`, 자치령은 `a Korean dominion`으로 맞췄다. 실제 조건은 `Together for Victory`이며, 이름이 다른 기존 툴팁 키 `HOK_KOR_chinese_government_mtg_tt`도 변경하지 않았다.
- 산둥·칭다오와 산둥군벌의 적격 본토를 확보하는 `founding territory`를 다른 중국 국가의 지지도에 따른 추가 편입과 구분했다. `defection share`는 실제 영토 제공국의 군대·함대·공군·장비·연료에 적용되는 귀순 비율을 뜻한다. 기존 지휘관 제외, 완전 편입으로 소멸하는 산둥군벌의 잔여 물자 폐기, 비행장 우선 확보·필요시 1단계 신설, 보호 지역 제외와 일반 외교 규칙을 보존했다.
- 일본 봉기의 지지도 기준은 봉기 직전이며, 영토·군대·비축 물자의 **민주세력 배분분**이 최소 10%·최대 90%라는 점과 실제 영토가 주 단위로 나뉜다는 점을 명시했다. 산둥 효과에서는 폐기 대상의 소유주를 `the Shandong warlord state`로 밝혀 새 정부와 혼동하지 않도록 했다.
- 비밀 정보국은 한국의 조직을 설명하는 `Secret Intelligence Service`로 옮겼다. 영국 MI6의 정체성이나 원문에 없는 역사 설명을 추가하지 않았다. 중점은 공통 재무장 진입부에 연결되므로 민주주의 전용 기관처럼 서술하지 않았다.

한국어와 영어를 문장별로 대조하고 별도 에이전트의 독립 의미 검토와 영어만 읽는 검토를 수행했다. 산둥 5키와 변경 중점 6키는 같은 한국어에 대응하는 RT56 내장 영어를 원문 대조 후 활용했다. 이 11키에서는 일본 안내의 수혜자와 산둥 안내 두 곳의 특정 국가 표현을 명확히 한 **3개 값**이 RT56 내장 영어와 다르다. 따로 번역한 지원·정보국 15키 중 표현이 다른 10키를 합하면 이번 26키의 영어 차이는 총 13값이다. 의미 차이나 신규 누락으로 집계하지 않았고 RT56 원본에 덮어쓰지도 않았다.

## RT56 대조와 사용 구성

신규·변경 한국어 **26키**는 일반판과 RT56에서 동일하다. RT56에는 해당 영어가 이미 내장돼 있으며, 일반판 소스의 영어 채널 한국어와 구분해 대조했다.

| RT56 현지화 | 파일 | 고유 키 | 전체 정의 |
| --- | ---: | ---: | ---: |
| 한국어 | 51 | 4,238 | 4,251 |
| 내장 영어 | 50 | 2,934 | 2,947 |

각 언어의 기존 장비 13키 중복은 의도된 정의로 구분했다. 한국어에만 있는 1,304키는 비한국 호스트 장비 1,291키와 기존 공용 함장 UI 13키이며, 이번 신규 영어 누락으로 계산하지 않는다.

**RT56 영어 플레이에서는 RT56 내장 영어를 사용하고 이 일반판 번역 서브모드는 비활성화한다.** 주 ID와 판별 표시 차이를 유지했으며, 두 판의 업데이트를 대조했다는 사실이 이 서브모드의 RT56 호환성 완료를 뜻하지 않는다. [RT56 구성 기록](rt56-compatibility-design.md)을 따른다.

## 일반판 원본의 확인 사항

일본 봉기 중점의 가용 조건에서 한국의 세력 맹주 조건이 삭제됐지만, 일반판 `common/scripted_effects/HOK_KOR_democratic_intelligence_effects.txt`는 반군의 세력 가입에 `KOR`의 `add_to_faction`만 사용한다. RT56에는 맹주를 통한 가입을 처리하는 별도 `faction_leader` 분기가 있다.

따라서 **한국이 맹주가 아닌 경우 일반판의 반군 가입은 실제 게임 확인이 필요하다.** 이것은 스크립트 차이의 정적 확인이며 가입 실패를 실행으로 확정한 결과가 아니다. 참전은 별도의 `add_to_war` 명령이므로 가입의 불확실성을 참전 실패와 동일시하지 않는다. 영어는 가입·자동 참전을 안내하는 한국어를 보존했으며, 번역 작업으로 일반판 게임 코드를 수정하지 않았다.

## 검증과 한계

기존 외부 `20261020-implementation-01/audit_localisation.py`의 읽기·토큰 검사 함수를 `python -B`로 재사용했다. 기존 검사기나 과거 출력은 수정하지 않았다. 이전 일반판 `0c19f58`과의 전체 한국어 값 비교로 신규 20키·변경 6키·삭제 0키를 확정했고, 이번 17개 `$KEY$` 참조는 번역 또는 설치 게임의 영어 정의에 모두 대응한다. 신규·기존 산둥 효과 두 키의 영어는 일치한다. 새 파일은 대응 원문의 BOM·줄바꿈을 따르고, 기존 중점 파일은 6개 값 외의 바이트를 보존했다.
